Applied Loop

ぼうけんのしょ

理解ギャップを、地図に残す。

vibe coding で通り過ぎた「わかったつもり」を、しれん（理解チェック）とずかん（つまずき）に変える。ローカルで回る MCP ループ。UI は Living Atlas。

GitHub を見る 始め方案内へ

いまはセルフホスト dogfood。SaaS / マルチユーザーはまだない。

最短3手（じゅんび）

初日はツール名を覚えなくてよい。順番だけ守る。

①

サンプルしれんを1問

Web の『たたかう』で提出。合否は待たなくてよい

②

自分の LLM に MCP をつなぐ

道を選び、貼る文を1回呼ぶ。ツール名は覚えなくてよい

③

（任意）監視リポジトリ

仕事 repo を選んで鉤。未選択なら commit からは溜まらない

本運用のループ

つなぐ

アプリ + 合言葉 + 自分の LLM（MCP）。操作の正典はツール。

集める

監視中 repo の commit、または会話の request_gate。PR 作成だけでは増えない。

進める

朝の要約 → しれん → ずかん。わかったつもりを地図に残す。

手元で始める

git clone https://github.com/shin9898/applied-loop.git
cd applied-loop
npm run setup
npm run dev:all
# → http://localhost:3100/setup

正本は docs/onboarding.md。仲間向け最短は README 冒頭。
