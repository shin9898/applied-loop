こんな困りごと向け

速度だけが先に行き、理解と記録が置いていかれる——その穴を埋める。

コードは進むのに、説明できない

AIとマージできたのに、レビューで「なぜこの設計？」と聞かれて言葉が出ない。

学びがチャットに消える

わかったつもりでも、セッションが終わると痕跡も結論も残らない。

同じ勘違いが戻ってくる

先週通した話が、別タスクで同じミスとして再発する。

なにが解消できるか

教材を増やすのではなく、自分の作業（コミット・セッション）を理解の材料にする。

01

説明できるまで、あとから試せる

コミットや会話から理解チェック（しれん）が届く。合否はあとから見られる。

02

つまずきが地図に残る

答えた結果がずかんに貯まる。未解消や再発を追える。

03

今日の一手が朝に見える

朝の要約から、いま解くべきしれん／関連する学びに戻れる。

なにができるか

UI の呼び名はゲーム風。中身は全部、理解を残すための機能。

しれん（理解チェック）

自分の差分について出題され、Web か自分の LLM から答える。

ずかん（つまずき一覧）

間違えた論点・誤解を一覧で追い、再出題につなげる。

ちず（進捗の地図）

未消化の理解ギャップをクエスト（！）として眺める。

自分の LLM とつなぐ

Claude / Cursor / Codex などに MCP を1回貼る。操作の正典はツール側。

どう動くか

初日はツール名を覚えなくてよい。起動 → 働く → 答える、の3手。

①

手元で起動する

clone → setup → ブラウザでじゅんび。最初の1問は Web で提出してよい。

②

いつもどおり働く

監視中の repo で commit、または会話から出題。PR 作成だけでは溜まらない。

③

答えて、地図に残す

しれんに答える → つまずきがずかんへ。朝に次の一手を見る。

手元で始める

自分のマシンで動かすオープンソース。API キーを渡してクラウド学習させる製品ではない。 

git clone https://github.com/shin9898/applied-loop.git
cd applied-loop
npm run setup
npm run dev:all
# → http://localhost:3100/setup
